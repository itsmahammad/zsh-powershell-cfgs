# Dotfiles

My shell configuration for Linux, WSL, and PowerShell.

## Structure

- `zsh/` — Zsh and Powerlevel10k configuration
- `powershell/` — PowerShell 7 profile

Dependencies such as Oh My Zsh, Powerlevel10k, and Zsh plugins
should be installed separately on each machine.

## Zsh setup

Dependencies:
- Zsh
- Git and curl
- fzf
- Oh My Zsh
- Powerlevel10k
- zsh-autosuggestions
- zsh-syntax-highlighting

The `.zshrc` configuration also enables the Oh My Zsh
plugins for Git, Docker, kubectl, Terraform, Ansible,
sudo, and command-not-found.

## PowerShell 7 setup

- PowerShell 7
- Oh My Posh
- Catppuccin Mocha theme
